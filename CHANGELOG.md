# Changelog

## 1.0.0 (build 1) — 2026-11-18

First release.

- Local profile with optional PIN and fingerprint lock.
- Terms, subjects with weighted grading components, scores and planned assessments.
- Grade engine: component averages, weighted subject percent, configurable grade scale and rounding, units-weighted GWA, cumulative GWA, target score solver.
- Home dashboard with GWA ruler, next assessment, subjects needing attention.
- Scores timeline, planner, progress charts, history, GWA and target calculator.
- Local assessment reminders.
- JSON backup and restore, CSV export, PDF grade report.
- Dark and light themes.
